#### 仕様書のログ関連規約の再確認

`docs/spec.md`より以下を確認：

**ログファイル仕様**:
- JSONL形式（各行が独立したJSONオブジェクト）
- ログエントリ構造: `{timestamp, level, message, app, namespace, type}`
- timestamp: Unix timestamp（ミリ秒）
- type: "stdout" または "stderr"

**ログファイル優先順位**:
1. `out_file` + `error_file` が指定時 → これらを使用、`log_file`は無視
2. `log_file` のみ指定時 → stdout/stderrを同一ファイルに出力
3. 未指定時 → デフォルトパス `~/.masuidrive-procman/app-logs/[name].jsonl`

**ログ表示仕様**:
- デフォルト: JSONL形式（最新100行）
- `--human`: `[アプリ名] YY/MM/DD HH:mm:ss > 本文`形式、アプリ別色分け
- `--stream`: リアルタイムストリーミング表示
- `-n <lines>`: 表示行数指定

#### ログファイル配置戦略の決定

**配置場所**: `~/.masuidrive-procman/app-logs/`
**ファイルパーミッション**: 0644（所有者読み書き、その他読み取りのみ）
**ディレクトリ構造**:
```
~/.masuidrive-procman/app-logs/
├── [app-name].jsonl           # 統合ログ（log_file指定時）
├── [app-name]-out.jsonl       # stdout専用（out_file指定時）
└── [app-name]-error.jsonl     # stderr専用（error_file指定時）
```
