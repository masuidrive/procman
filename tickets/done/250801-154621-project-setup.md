## Considerations

- **Node.js バージョン管理**: 
  - Node.js 18.x LTS の機能（ES2022 サポート、fetch API 等）を適切に活用する
  - .nvmrc でバージョンを固定し、開発環境の一貫性を保つ
- **型定義とアーキテクチャ**:
  - 今後の開発で必要となる基本的な型定義（ProcessInfo, ServiceConfig等）を src/types/ に配置
  - CLI・Daemon・共有モジュールの分離を意識した構造にする
- **npm パッケージ配布対応**:
  - @masuidrive/procman として npm publish 可能な設定にする
  - package.json の bin 設定で npx 実行に対応する
  - 将来的に npx @masuidrive/procman でグローバルインストール不要で実行可能にする
- **テスト環境統合**:
  - bin/test-*.sh スクリプトとの整合性を保つ
  - Vitest と既存のテストスクリプトが連携できるようにする
- **開発体験向上**:
  - tsx による開発時のホットリロード対応
  - ESLint・Prettier による自動フォーマット・品質チェック
  - npm scripts を充実させて開発フローを効率化
- **ビルド最適化**:
  - TypeScript の strict モードを有効にして型安全性を確保
  - source map 生成でデバッグしやすくする
  - 不要なファイルを除外してビルドサイズを最適化
