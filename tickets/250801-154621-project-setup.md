# Project Setup - プロジェクト基盤設定

## Overview

@masuidrive/procmanプロジェクトの開発基盤を構築する。Node.js 18.x + TypeScript環境を整備し、テスト・リント環境を設定する。PoC検証結果を踏まえた技術スタックに基づいて実装する。

## Prerequisite

- Node.js 18.x LTS がインストールされていること
- npm または yarn が使用可能であること
- 仕様書・アーキテクチャ文書が確認済みであること

## Tasks

### Prepare: Context Alignment

- [ ] PoCレポートと技術スタック文書を再確認し、実装方針を明確化する
- [ ] プロジェクトのディレクトリ構造と技術要件を整理する
- [ ] 開発環境の前提条件を確認・文書化する
- [ ] `git commit`

### Phase 1: Node.js プロジェクト初期化

- [ ] package.json を作成し、基本的なメタデータを設定する
  - name: @masuidrive/procman
  - version: 0.1.0
  - Node.js 18.x のengines指定
  - bin設定で"procman": "dist/cli.js"を明示的に記載（npx実行のため重要）
- [ ] `.nvmrc` でNode.jsバージョンを固定（18.x）
- [ ] 基本的なディレクトリ構造を作成する
  ```
  src/
  ├── cli/          # CLI Client
  ├── daemon/       # Daemon Process
  ├── shared/       # 共通モジュール
  └── types/        # 型定義ファイル
  tests/            # テストファイル
  ```
- [ ] `git commit`

### Phase 2: TypeScript環境設定

- [ ] TypeScript と @types/node をインストール
- [ ] tsxパッケージをインストール（TypeScript実行用）
- [ ] tsconfig.json を設定
  - target: ES2022
  - module: ESNext
  - moduleResolution: Node
  - strict モード有効
  - outDir: dist/
- [ ] src/cli/index.ts に最小限のCLIエントリーポイントを作成
- [ ] TypeScript のビルドが正常に動作することを確認
- [ ] `git commit`

### Phase 3: テスト環境（Vitest）設定

- [ ] Vitest と関連パッケージをインストール
- [ ] vitest.config.ts を設定
  - TypeScript対応
  - test ディレクトリの指定
  - coverage設定
- [ ] 簡単なサンプルテストファイルを作成し、テストが実行できることを確認
- [ ] package.json にテストスクリプトを追加
- [ ] `git commit`

### Phase 4: リント・フォーマット環境設定

- [ ] ESLint と Prettier をインストール
- [ ] .eslintrc.js を設定
  - TypeScript対応
  - 基本的なルール設定
- [ ] .prettierrc を設定
- [ ] package.json にlint・formatスクリプトを追加
- [ ] 既存コードにリント・フォーマットを適用
- [ ] `git commit`

### Phase 5: CLI基盤設定

- [ ] Commander.js をインストール
- [ ] src/cli/index.ts にCommander.jsの基本セットアップを実装
- [ ] 基本的なヘルプ表示機能を実装
- [ ] npx経由での実行をテストする
- [ ] `git commit`

### Final Phase: Quality Assurance

- [ ] 全ての設定ファイルを確認し整合性をチェック
- [ ] package.json の dependencies/devDependencies が適切か確認
- [ ] TypeScriptビルドが正常に動作することを確認
- [ ] テストの実行が正常に動作することを確認
- [ ] ESLint・Prettierが正常に動作することを確認
- [ ] CLI の基本的な起動確認
- [ ] READMEファイルに開発環境のセットアップ手順を記載
- [ ] `git commit`

## Considerations

- Node.js 18.x LTS の機能を適切に活用する
- 今後の開発で必要となる基本的な型定義も含める
- npmパッケージとしての配布を考慮した設定にする（@masuidrive/procmanとして）
- npx @masuidrive/procman でグローバルインストールせずに実行可能にする
- bin/test-*.sh スクリプトの存在を前提とする
- 開発体験を向上させるためのスクリプト類も整備する
