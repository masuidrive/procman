# Ticket Overview

CLIクライアントの基本コマンド実装

## Prerequisite

## Overview

@masuidrive/procmanのCLIクライアントを実装します。このCLIクライアントは、デーモンプロセスとIPC通信を行い、各種コマンドを処理するためのインターフェースを提供します。

実装するコマンドは以下の通りです：
- **load**: 設定ファイルの読み込みとデーモン起動
- **start**: プロセスの起動
- **stop**: プロセスの停止 
- **restart**: プロセスの再起動
- **exit**: デーモンの終了
- **list/ls**: プロセス一覧表示
- **log**: ログ表示（リアルタイムストリーミング対応）
- **clear-log**: ログクリア
- **help/prompt**: 使用方法の表示（AIコーディングアシスタント用）

これらのコマンドは、Unix Domain Socket（Unix系）またはNamed Pipe（Windows）を使用してデーモンプロセスと通信を行います。

## E2E test scenarios

- デーモンが起動していない状態で各コマンドを実行し、適切なエラーメッセージが表示されること
- 設定ファイルをloadしてデーモンを起動し、listコマンドでプロセス一覧が表示されること
- start/stop/restartコマンドでプロセスの状態が適切に変更されること
- logコマンドで過去のログが表示され、--streamオプションでリアルタイムログが表示されること
- exitコマンドですべてのプロセスとデーモンが正しく終了すること
